# Tables of the night evaluation of 2026-10-20

Main scores first. exact: each table set of the label against each returned set (a top-k list is one set, each AMIGO interpretation one set), a hit only when equal: R the label's sets found, P the returned sets that are one of them, CR every set found. interp.: each query of the label against the returned set closest to it, on tables: R and P averaged over the queries, CR when every query is held whole by one set; returned sets close to no query cost nothing there. interp. set P is from the other side: each returned set, duplicates dropped, against the query it is closest to (the share of its tables in that query), averaged over the returned sets. pooled: every returned table against every table of the label, both pooled, so which tables go together is lost; it is the level a table retriever's list is scored on as it is. soft: as exact, but a returned set holding a label set counts. Gold-label tables show exact match (one returned set equals the gold tables) and soft match (one holds them all): with one gold set CR repeats R and P counts every other valid set as wrong. No answer: questions with no returned table, scored 0 everywhere. No gold table: the label reads none; table R and CR count it found, a footprint is held by any returned set. Precision is a lower bound: the labels are incomplete.
Means and worst are over BIRD, Spider and MMQA: not every method finished TACO-US stage A.
n = questions per lake; failures count as described in 8.3.
